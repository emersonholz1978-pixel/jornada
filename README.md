# OAB FÁCIL

Estrutura inicial do site institucional e da futura área do aluno do projeto OAB FÁCIL.

## Conteúdo

- Página inicial responsiva com identidade azul-marinho e dourado.
- Apresentação do método, 1ª fase e 2ª fase.
- Formulário inicial de cadastro com aceite de privacidade.
- Área de materiais e progresso preparada para evolução.
- Informações de contato administrativo e apoio voluntário.

## Publicação no Render

Este projeto é um site estático servido por Nginx.

1. Envie todos os arquivos deste diretório para o repositório do GitHub.
2. No Render, crie um serviço **Web Service** conectado ao repositório.
3. Selecione **Docker** como ambiente.
4. Use a branch `main` e faça o deploy.

O formulário atual é demonstrativo: para armazenar cadastros com segurança, será necessário conectar um backend ou serviço de formulários antes da publicação definitiva.
